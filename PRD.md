# Product Requirements Document (PRD)
# ISP Prefix & Upstream Usage Collector Dashboard (`collector-prefix`)

**Document Version:** 1.0.0  
**Target Environment:** FreeBSD Routers with BIRD BGP, ~10 Gbps Edge Upstream / IX Links  
**Architecture Classification:** High-throughput Network Telemetry Ingestion, Aggregation, and Analytics UI  

---

## 1. Executive Summary & Core Objectives

### 1.1 Overview
The **ISP Prefix & Upstream Usage Collector** is a high-performance network telemetry and visual analytics platform designed for Internet Service Providers (ISPs). It captures real-time flow telemetry from edge routers, enriches flows with Autonomous System Numbers (ASNs) and ISP-specific prefix hierarchy tags, persists them in an ultra-fast columnar database (ClickHouse), and visualizes granular traffic patterns via an interactive web interface.

### 1.2 Core Capabilities
1. **Hierarchical Prefix Filtering & Rollup:**
   * Organize ISP-owned IP subnets in a nested tree structure (e.g., Parent `/20`, `/21`, `/22`, `/23` expanding into granular `/24` sub-prefixes).
   * Filter and aggregate utilization by specific sub-prefixes or aggregate entire CIDR blocks.
2. **Upstream Transit & IX Interface Breakdown:**
   * Segment and isolate traffic per Transit (`IPT.CBN`, `IPT.iFORTE`, `IPT.NTT-SGCC`, `IPT.SDI`, `IPT.TELKOM@JKT`, etc.) and Internet Exchange (`LC.AIX`, `LC.CDIX`, `LC.DE-CIX`, `LC.IIX`, `LC.ISIX`, `LC.JKT-IX`, `LC.OIXP`).
3. **Multi-Router & 10 Gbps Line-Rate Ingestion:**
   * Ingest sampled NetFlow v9/IPFIX telemetry generated by FreeBSD's kernel-level `ng_netflow` module at 1:1000 sampling without packet loss or CPU saturation.
4. **Real-time ASN Flow Analytics:**
   * Visualize end-to-end traffic distribution via an interactive Sankey / Alluvial diagram (`Source ASNs → Local ISP AS (e.g., AS45287) → Upstream Transits / Destination ASNs`).
5. **Operational Telemetry & Observability:**
   * Live tracking of active exporters, flow ingestion rate, database health, peak/average metrics, and customizable auto-refresh intervals (10s, 30s, 1m).

## 3. Detailed Component Specifications

### 3.1 Flow Exporter: FreeBSD `ng_netflow` (Kernel Level)
* **Kernel Mechanism:** FreeBSD Netgraph (`ng_netflow`, `ng_ether`, `ng_ksocket`).
* **Sampling Rate:** Configured to `1:1000` (or `1:500`) to guarantee minimal CPU footprint under 10Gbps line rate.
* **Export Protocol:** NetFlow v9 or IPFIX over UDP to the central collector on port `2055`.
* **Exported Attributes:**
  * Ingress Interface Index (`ifIndex_in`)
  * Egress Interface Index (`ifIndex_out`)
  * Source IPv4 / Destination IPv4
  * Source Port / Destination Port / Protocol
  * Packet Count & Byte Count
  * Sampling Interval (1000)

### 3.2 Flow Collector & Enrichment Engine (Go / `goflow2`)
* **UDP Listener:** High-throughput non-blocking UDP socket on port `2055`.
* **Sample Normalization:** Automatically scales `bytes_total = sampled_bytes * sampling_rate` and `packets_total = sampled_packets * sampling_rate`.
* **ASN Enrichment:** 
  * Integrates MaxMind `GeoLite2-ASN.mmdb` (or IP2Location) for instant memory-mapped IPv4/IPv6-to-ASN resolution.
  * Resolves `src_asn` (Source ASN) and `dst_asn` (Destination ASN).
* **Traffic Direction Classification:**
  * Compares IP addresses against configured ISP IP prefix tables.
  * If `dst_ip` matches ISP CIDR $\rightarrow$ **Inbound** (`is_inbound = 1`, `isp_prefix = matched_cidr`).
  * If `src_ip` matches ISP CIDR $\rightarrow$ **Outbound** (`is_inbound = 0`, `isp_prefix = matched_cidr`).
* **Interface Enrichment:**
  * Maps `(router_ip, ifIndex)` to human-readable names (`IPT.CBN`, `IPT.iFORTE`, `LC.DE-CIX`, etc.) based on the Router Interface Registry configuration.
* **Batching & Ingestion:**
  * Buffers records in memory and performs bulk inserts into ClickHouse every 1 second or 25,000 records.

### 3.3 Storage Layer: ClickHouse Time-Series Schema
ClickHouse is configured with partitioned columnar storage and Materialized Views for sub-50ms query response times across multi-billion flow datasets.

#### Table DDL: Raw Flows (`flows_raw`)
```sql
CREATE TABLE IF NOT EXISTS flows_raw (
    timestamp DateTime CODEC(DoubleDelta, LZ4),
    router_id LowCardinality(String),
    in_iface UInt32,
    out_iface UInt32,
    interface_name LowCardinality(String),
    src_ip IPv4,
    dst_ip IPv4,
    src_asn UInt32,
    dst_asn UInt32,
    proto UInt8,
    bytes UInt64,
    packets UInt64,
    is_inbound UInt8,
    isp_prefix LowCardinality(String)
) ENGINE = MergeTree()
PARTITION BY toDate(timestamp)
ORDER BY (is_inbound, interface_name, isp_prefix, timestamp)
TTL timestamp + INTERVAL 7 DAY;
```

#### Materialized View: 1-Minute Aggregation (`flows_1m`)
```sql
CREATE TABLE IF NOT EXISTS flows_1m_by_prefix_and_iface (
    time_bucket DateTime,
    interface_name LowCardinality(String),
    isp_prefix LowCardinality(String),
    is_inbound UInt8,
    total_bytes SimpleAggregateFunction(sum, UInt64),
    total_packets SimpleAggregateFunction(sum, UInt64)
) ENGINE = AggregatingMergeTree()
PARTITION BY toDate(time_bucket)
ORDER BY (is_inbound, interface_name, isp_prefix, time_bucket)
TTL time_bucket + INTERVAL 30 DAY;

CREATE MATERIALIZED VIEW IF NOT EXISTS mv_flows_1m_by_prefix_and_iface
TO flows_1m_by_prefix_and_iface AS
SELECT
    toStartOfInterval(timestamp, INTERVAL 1 MINUTE) AS time_bucket,
    interface_name,
    isp_prefix,
    is_inbound,
    sum(bytes) AS total_bytes,
    sum(packets) AS total_packets
FROM flows_raw
GROUP BY time_bucket, interface_name, isp_prefix, is_inbound;
```

#### Materialized View: 5-Minute ASN Flow Matrix (`flows_5m_asn_matrix`)
```sql
CREATE TABLE IF NOT EXISTS flows_5m_asn_matrix (
    time_bucket DateTime,
    interface_name LowCardinality(String),
    src_asn UInt32,
    dst_asn UInt32,
    isp_prefix LowCardinality(String),
    is_inbound UInt8,
    total_bytes SimpleAggregateFunction(sum, UInt64)
) ENGINE = AggregatingMergeTree()
PARTITION BY toDate(time_bucket)
ORDER BY (is_inbound, interface_name, src_asn, dst_asn, time_bucket)
TTL time_bucket + INTERVAL 365 DAY;

CREATE MATERIALIZED VIEW IF NOT EXISTS mv_flows_5m_asn_matrix
TO flows_5m_asn_matrix AS
SELECT
    toStartOfInterval(timestamp, INTERVAL 5 MINUTE) AS time_bucket,
    interface_name,
    src_asn,
    dst_asn,
    isp_prefix,
    is_inbound,
    sum(bytes) AS total_bytes
FROM flows_raw
GROUP BY time_bucket, interface_name, src_asn, dst_asn, isp_prefix, is_inbound;
```

## 6. FreeBSD Router Exporter Configuration Guide

To enable `ng_netflow` on FreeBSD for 10G interfaces with 1:1000 sampling:

### 6.1 Kernel Module Loading (`/boot/loader.conf`)
```
netgraph_load="YES"
ng_ether_load="YES"
ng_netflow_load="YES"
ng_ksocket_load="YES"
```

### 6.2 Netgraph Hook Script (`/usr/local/etc/rc.d/netflow_exporter.sh`)
```bash
#!/bin/sh
# Setup ng_netflow with 1:1000 sampling and export to Collector (UDP 2055)

COLLECTOR_IP="192.168.10.50"
COLLECTOR_PORT="2055"
ROUTER_IFACE="ix0"

# Create netflow node
ngctl mkpeer ${ROUTER_IFACE}: netflow lower iface0
ngctl name ${ROUTER_IFACE}:lower netflow
ngctl connect ${ROUTER_IFACE}: netflow: upper out0

# Create UDP export socket
ngctl mkpeer netflow: ksocket export inet/dgram/udp
ngctl msg netflow:export connect inet/${COLLECTOR_IP}:${COLLECTOR_PORT}

# Set 1:1000 sampling rate on iface0 (conf=1 means 1000 sample rate in FreeBSD ng_netflow)
ngctl msg netflow: setconfig { iface=0 conf=1000 }
```

## 8. Verification & Acceptance Criteria
1. **Sampling Accuracy:** Total calculated bps across all interfaces matches SNMP interface octet counters within $\pm 1\%$.
2. **Query Latency:** 1-hour time-series and Sankey queries across 53 prefixes and 12 interfaces return in $< 100\text{ms}$.
3. **Prefix Filtering:** Selecting a parent `/20` displays the exact sum of all 16 child `/24`s; unchecking specific `/24` subnets subtracts their utilization dynamically.
4. **Resilience:** Router exporter failure or burst traffic (10Gbps flood) does not crash the collector or backlog the ClickHouse insertion queue.
